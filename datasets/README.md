# Local research datasets

CSV files in this directory are intentionally excluded from GitHub by
`.gitignore`. They can contain large source files or material subject to separate
licensing and attribution requirements.

To reproduce the existing academic experiment locally, copy the following files
from your private original project backup into this folder:

- `mmc2.csv` — the original published source file; do not upload it to the AI Lab.
- `roadguard_realworld_derived.csv` — the model-compatible processed CSV used by
  the current evaluation workflow.

Before redistributing either file, confirm the source license and include the
required attribution. The source-to-processed-data transformation must be fully
documented before using the processed labels as research evidence.
